Bem-vindo ao meu repositório dedicado à disciplina de **Linguagem de Programação I**, parte da grade do curso de Análise e Desenvolvimento de Sistemas da **FATEC Sorocaba**.

Aqui, documentei a construção da minha base algorítmica e lógica de programação utilizando a linguagem **C**. O foco principal desta matéria é a compreensão do paradigma estruturado, entendendo "por baixo dos panos" como os dados são alocados, manipulados e processados pelo computador.

---

## 🎯 Objetivos

Os códigos e exercícios deste repositório ilustram a evolução desde os conceitos mais básicos de entrada e saída até a manipulação de estruturas lógicas complexas. As principais áreas exploradas incluem:

- **Fundamentos da Lógica:** Variáveis, tipos de dados primitivos, operadores lógicos/aritméticos e sintaxe base da linguagem.
- **Controle de Fluxo:** Implementação de estruturas condicionais (`if/else`, `switch`) e laços de repetição (`for`, `while`, `do-while`) para controle de execução.
- **Estruturas de Dados Estáticas:** Manipulação de vetores (arrays unidimensionais), matrizes multidimensionais e tratamento de cadeias de caracteres (strings).
- **Modularização:** Criação de funções e sub-rotinas para dividir problemas complexos em blocos de código menores, limpos e reutilizáveis.
- **Tópicos Avançados (C):** Introdução aos ponteiros, passagem de parâmetros (por valor e referência) e o uso de `structs` para agrupamento de variáveis.

## 🛠️ Pré-requisitos

Para compilar e executar os códigos deste repositório, você precisará instalado em sua máquina:

- **Compilador GCC**: Essencial para compilar os arquivos de código-fonte (`.c`).
- **Ambiente/IDE de sua preferência**: Visual Studio Code, Code::Blocks, ou qualquer outro editor de texto com suporte à linguagem C.

## 🚀 Como Executar

1. Clone este repositório em sua máquina local:
```bash
   git clone [https://github.com/Romerac/Linguagem-de-Programacao-1-C.git](https://github.com/Romerac/Linguagem-de-Programacao-1-C.git)
```

2. Abra a pasta do exercício ou projeto que deseja testar.

3. Se estiver utilizando o terminal com o GCC, compile o arquivo .c com o seguinte comando:

```bash
   gcc nome_do_arquivo.c -o nome_do_arquivo
```

4. Execute o binário gerado na sua máquina:
```bash
    No Windows: nome_do_arquivo.exe
```
```bash
    No Linux/Mac: ./nome_do_arquivo
```
